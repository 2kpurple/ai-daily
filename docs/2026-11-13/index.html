Gemini 4 Hydrogen 发布。

Google · 11-13 02:00

编辑简介

Gemini 4 Hydrogen 是 Google 新推出的偏速度与执行的模型，与更擅长深度推理的 Carbon、Argon 形成搭配。它同时覆盖 Gemini App、Google 搜索和开发者接口，普通用户在常用入口就能体验。官方给出的成绩和速度对比来自 Google 自己的发布文章，实际效果可以用自己的问题检验。

原文正文要点

Google 推出主打速度与 Agent 执行的新模型，覆盖 Gemini App、Google 搜索、AI Studio 与 Gemini API 全部档位。官方称其在 Artificial Analysis 智能指数上略高于 Argon（51 比 50），完成任务速度是 3.8 Flash 的 2.5 倍，编造内容减少 5 倍以上；API 定价为每百万 token 输入 $1.5、输出 $7.5。Google 搜索同日全面接入 Hydrogen，官方称这是搜索迄今最大的一次模型升级，复杂的多段提问可得到对比表与图片。Google｜搜索升级（11-13 02:00）
