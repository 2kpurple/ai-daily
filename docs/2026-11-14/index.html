ChatGPT Wallet 发布。

OpenAI · 11-13

编辑简介

ChatGPT Wallet 是让 AI Agent 在用户批准后代为付款的钱包。每笔购买都要用户核对并用生物识别确认，商家拿到的是支付令牌而不是真实卡号，原有的卡片权益和争议保障仍然有效。目前只在 dots 中向美国的 ChatGPT Pro 用户开放，OpenAI 同时发布了帮助商家接受 Agent 付款的指南。

原文正文要点

用户每次付款前要核对商品、总价和所选的卡，再通过 Face ID 或指纹确认；支付网络生成支付令牌，商家和 Agent 都拿不到真实卡号。由 American Express、Mastercard、Visa 合作推出，先在 dots 中向美国 18 岁以上的 ChatGPT Pro 用户开放。OpenAI（11-13）
